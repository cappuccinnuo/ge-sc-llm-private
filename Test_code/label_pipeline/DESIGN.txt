一、结论与适用边界
当前源码到标签流程尚不能宣称完全复现论文或完全等同作者发布资产。普通节点的整段范围、合成节点位置、漏洞类别筛选、标注数据版本、部分发布资产的异常记录，均会独立改变节点标签。
新方案将“公开来源可审计”和“接近作者端点布局”结合。它不读取作者旧节点标签来生成新标签，也不按目标正例数量调参。
author-endpoints 是显式兼容坐标政策，不是每个节点真实执行行的语义定义。特别是合成节点 marker 保留了观察到的历史零基行为。
公开CSV完整注入区间是一种基准监督政策，不意味着区间内每行都是最小漏洞根因；存在疑点的原始CSV不自动修订。

二、原始数据核验
当前SolidiFI、SmartBugs、MANDO-HGT副本均为干净Git工作区，commit见 verification.json。
前身MANDO-HGT自带七类 vulnerabilities.json，旧交接文档“原始JSON未公开/缺失”需要限定为MANDO-LLM特定转换资产，不能再说前身JSON不存在。
选中295份SolidiFI文件类别组合、8220条CSV记录，其完整范围并集与HGT JSON全部一致。所有区间数值和源码边界通过核验。
上游数据仍有疑点：
- 重入BugLog_18.csv记录105,10与111,6重叠，而对应函数分别为105..110和111..120；长度疑似互换。原数据及前身转换已经如此。
- tx.origin/BugLog_36.csv多一个无名第五列。新代码报告这一列，不把它当loc/length。
- buggy_20各类作者图记录缺的两行有真实代码和行内块注释，不应为了贴作者删掉整行。
- SmartBugs的0xf70...当前公开标注44为调用语句，HGT旧JSON45为闭括号。新方案使用当前源码配套44，报告版本差。
- 部分作者图记录越过对应预处理源码行数，具体转换/关联原因尚未确定。不能复制这些值当成新的独立真值。
历史命名“每类40份SolidiFI”也不适用于全部七类：算术、时间操纵、低级调用为45份，其余各40份。

三、处理流程
1. 使用显式合约清单，校验文件覆盖和0/1标签，固定文件哈希。
2. SmartBugs按漏洞类别、标注路径和源码对应关系选择；同名不等于同一个来源。SolidiFI按固定类别目录取命名loc/length，验证区间并合并每文件一条记录，同时保留重复、重叠、额外列的审计。
3. 源码以canonical公开文件为准；本地只允许预处理正文和行位置不变的注释变化或pragma变化。不满足一致性检查就停止。
4. 精确重现原仓库预处理文本，并追踪存活非空白字符的原始行号；注释替代空格不携带标注来源。原始坐标与预处理坐标分别输出。
5. 从节点自身label独立提取端点：普通节点取末尾首/尾行；end_if/end_loop取label前缀的根起始marker。本地narrow坐标不覆盖这项兼容策略。七类113449个作者节点和本地重入/AC节点端点均已验证一致。
6. 只使用目标漏洞类别的公开标注求交。任意命中则挂载该文件整组目标类别记录以兼容原训练接口；node_label_evidence.jsonl另存真正命中的记录编号与坐标。非目标类别不得制造正例。
7. 合约标签始终独立保存；行级输入按合约正例名单取诱导子图，保留CFG+CG。不能按“存在正节点”推导或删改合约标签。
8. 生成结束后才加载作者节点标签作比较；精确节点身份和无类型边连接核对通过才报告逐节点标签差异。保留所有残差。
9. 非标签属性、边和已有token不变；导出、重读、训练标签消费接口和输入哈希逐项验证。

  node_label_evidence.jsonl：逐节点证据

  line_node_ids.json：行级子图ID对应关系
  manifest.json：来源、政策、统计、校验、哈希

五、仍待解决
- 原构图控制流边类型部分折叠为next；本地保留的边类型尚不等同作者完整8类。
- 函数名/参数数量与字符串匹配不能可靠解决重载、同名、调用空格等情况。
- 原始CSV的语义边界疑点需要人工或注入过程证据确认；不宜自动按函数边界改写基准。
- 作者异常标注的精确来源仍需作者转换脚本或对应数据快照。
- 新标签会改变节点训练任务，不应把其F1与作者原标签基线混称严格复现。DDG实验应先固定标签政策、图、特征和折清单。
- node_info_vulnerabilities为兼容训练挂整文件记录，不能直接把其全部lines当成该节点预测行；应使用显式节点坐标与单独映射。

六、运行与验证

重新生成七类（输出必须是新目录）：
python -B Test_code/label_pipeline/build_dataset.py --categories all --output Test_code/label_pipeline/artifacts/public_endpoints_rerun

本地图重入示例（输出必须是新目录）：
