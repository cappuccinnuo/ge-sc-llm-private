# CPn：<标题>（报告模板）

每个 Prompt 结束时按本模板写 `compile_repair/CPn_REPORT.md`。结构与 EdgeSem 的 EPn_REPORT 一致。每个数字给出来源（命令、产物路径、SHA256 或计数文件）。

## 实现
- 新增与修改的文件（路径、用途）；复制自冻结模块的文件写明来源路径与原 SHA256。
- 与 PROMPTS.md 不一致之处、原因、处理方式；需要用户决定的，单列并写明“已停止”。

## 真实验收
- 本 Prompt 验收节列出的每一项：预期值、实际值、是否通过。
- 失败、跳过与异常的计数与原因链；不把“未运行”写成“通过”。

## 测试与开发记录
- 测试命令与结果（通过/失败/跳过数）。
- 开发中出现过的失败及修正（保留，不删除）。

## 归档与复现
- 产物目录、seal 文件及其 SHA256；编译器版本与可执行文件 SHA256；Slither/crytic-compile 版本。
- 可直接复制运行的完整命令。

## 停止位置与后续边界
- 本 Prompt 没有做的事；下一个 Prompt 的前提是否满足。
