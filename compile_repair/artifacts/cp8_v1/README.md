规格见 PROMPTS r2.38 §4.8，记录见 docs/CHANGE_LOG.md §85。本目录只有模拟 LLM 的结果；真实模型的小样本运行等用户决定 D12（模型、API、费用上限）并确认 D10 后进行。没有发生任何真实 LLM 调用，费用 0。

## 实现

- `agents/llm.py`：客户端基类负责预算（调用数、令牌、美元，发送前检查）、按请求 SHA-256 缓存（命中不计费、可复现）与逐次调用记录；`HttpClient` 支持 Anthropic Messages API 与 OpenAI 兼容 API，密钥只在调用时从环境变量读取；`ScriptedClient` 用于测试与无授权运行。
- `agents/prompt.py`：D10 视图（文件编号 F1…，入口为 F1；导入字符串显示编号；注释按等长空格遮蔽、换行保留；编译器消息中的路径与文件名换成编号）、每个错误前后 `window` 行（带行号）与错误中点名的声明位置、K1–K3 检索内容（CP7，k=5）、唯一修复模板、语言核对提示。
- `agents/patch.py`：REPLACE / INSERT 块；原文行（含行号）与视图逐行比较，不一致整候选拒绝；改写只允许错误所在行（D7），新增任意位置；新代码含注释、文件不可编辑（第 3 步的库发布版文件）、块重叠、无改动均拒绝；导入字符串中的编号写回真实相对路径。
- `agents/stage1.py`：每轮 N 个候选；语言为 unknown 且错误全在解析阶段时先做一次语言核对（r2.16）；被拒候选与其编译错误进入下一轮；轮数、预算用尽或连续两轮未被接受时停止（交第二阶段，CP9）。`agent_from_config` 从 JSON 配置构造（只含密钥的环境变量名，含疑似密钥的配置直接拒绝）。
- `pipeline.py`：只有传入代理时才运行：规则不再改动时进行代理轮；每个有效候选在副本上编译，按（是否成功、错误数、改动字节、候选序号）取最优，再按原有接受规则（成功、错误减少且阶段不倒退、D27 阶段前进）接受；接受后回到规则循环；每个单元写 `llm_calls.json`。不传代理时行为不变。`cli repair --agent-config <json>`。
- 非测试文件 23 → 28（agents/ 5 个，PROMPTS 3.10 已列；stage2.py 留给 CP9）；测试 `tests/test_cp8.py` 22 项。

## 用于真实运行

- `agent_config.example.json`：配置模板，预算全为 0（任何调用都会在发送前被拒），由用户按 D12 填写。
- `build_knowledge.py <docs> <out> [--index <索引>] [--memory <targets> <run>]...`：构建封存的知识目录（云端示例：K1 3,791、K2 75、K3 72 条）。
- `dry_run.py`：上面的模拟运行。
- 待定参数：上下文行数 `window`（PROMPTS 3.5 第 1 条要求在基准上确定）、候选数 N 与轮数，在授权的小样本运行的 dev 划分上确定；当前默认 window 10、N 3、轮数 4、停滞 2 轮。
