## 用户批准的两项选择

1. 真实语料中有 51 处旧式构造函数名称。将 function C 的名称当作所属 contract C 的绑定引用，共用合约匿名名称；不把它改成不同名字而破坏构造函数语义。
2. 首次绑定清点得到 159 个整文件回退。用户同意先完成核验，回退阻止全量计划封存；不混入原名、不删样本、不执行部分语料探针后声称全量通过。复杂绑定扩展另行确定。

验收仍是冻结 grammar 检查，不是 Solidity 编译验证。本轮没有安装/执行 solc，没有运行新 HGT 训练或探针分类器。

## 声明绑定实现

- 收集合约、接口、库、函数、modifier、事件、结构体/字段、枚举/成员、状态变量、参数、局部和命名返回值；以源码字节位置标识声明。
- 按既有版本证据区分 legacy / modern 词法作用域，不猜编译器版本。同名不同作用域有不同身份。
- 支持有限的同文件类型、结构体成员、已知对象成员、单返回类型、具名结构体参数和明确 using 库扩展。重载、覆盖/隐藏、无法证明的 receiver、assembly 等显式回退。
- 所有角色共用 v 前缀，编号来自 source SHA 派生的固定随机排列，避开原文件已有 vN 拼写；不是按源码首次出现递增编号。
- 保留表预先固定并写入 policy.json；每文件保留名计数记录在结果中。用户自定义 transfer 等同名保留项也不改。
- 按绑定的字节区间替换，字符串/注释不改；不使用文件级同名替换。
- 整文件回退时 rewritten 等于原文，edits/bindings 为空；不提交部分改名或特征。

## 实际覆盖

256 是 category/file/source 身份数；同一源码同时用于合约和节点任务，合计 384 个 task×file 引用，不是 384 个独立源码。

|范围|源码身份|绑定可改写|绑定回退|依赖与投影通过|投影阻断|
|---|---:|---:|---:|---:|---:|
|重入|142|56|86|47|9|
|访问控制|114|41|73|40|1|
|合计|256|97|159|87|10|

97 个可改写源码共有 4,025 个声明级匿名映射（各文件内唯一）、9,594 处绑定替换。256 原文与 97 改写文的 grammar 检查通过；97 份改写的 AST 拓扑、保留关键字子串计数保持一致。其余文件保留原文，不能算匿名化成功。

绑定阻断的文件计数允许重叠：

|原因类别|文件数|
|---|---:|
|继承中的覆盖/隐藏或同名重载|107|
|无法唯一确定引用|45|
|无法证明表达式类型/成员接收者|37|
|super 调度不确定|19|
|assembly|17|
|版本证据不足或冲突|8|
|复杂调用目标|7|
|同作用域重复/重载|6|
|遮蔽初始化绑定不确定|4|

这些是当前转换器的支持边界，不等于源代码一定错误。独立编号改写接口及实现的同名函数，可能改变覆盖关系，不能为了覆盖率任意连到一个声明。

## 依赖事实与原 HCG 核验

|任务|task×file|通过|绑定回退|投影阻断|
|---|---:|---:|---:|---:|
|重入合约|142|47|86|9|
|重入节点|71|21|41|9|
|访问控制合约|114|40|73|1|
|访问控制节点|57|24|33|0|
|合计|384|132|233|19|

132 项通过同时要求：归档、当前原文、改名内存副本的 L1/L2/L3 数量、规范化后的完整证据、投影端点及关系计数相同；原图 fingerprint 不变。临时副本只改 code，token/标签/节点/原边保持不变，分析输出丢弃，没有写出新模型图。

原源码的编译版本元数据先按原 SHA 核验；不得把该元数据冒用给改名文。临时改名文只用未改的 pragma；支持范围或事实因此变化也必须判失败，不伪造“已经编译”的记录。

**剩余 19 项对应 10 个独立文件、36 个合成节点的歧义。** 原 end_if/end_loop 缺少唯一 AST ID。同一段 if 文本在多个函数中出现，但 success 绑定不同局部声明，匿名名不同。例：重入 buggy_15.sol 的一个 end_if，原文本是 if(!success){revert();}，存在三个精确源码候选，分别变为 v48、v2、v25。无法从保存文本确定选哪个，不能按最近行号猜。

源码绑定成功的重入 9 个 SolidiFI 文件全部受到这类投影阻断；因此不能把当前小子集结果推广到重入注入数据。

详见产物 projection_blockers.json，包含身份、节点、全部候选 AST/行号和改写文本。合成节点只是这里的 code 改写被阻断，不表示其原 CFG 边或原模型已被删除。

## 检查器修复与历史记录

8E 的通用反向字符串替换不适用于 vN：v2 也是固定分析路径名。首轮检查错误地把 analysis_path="v2" 当成匿名标识符还原。新检查器只还原 L1 symbol/definition 的名称部分、L2/L3 的声明描述 name 字段；路径、关系、角色和其他审计文本保持原样。

补充 aggregate 路径和状态初始化用例，证明不修改审计词汇且可检测事实/边篡改。首次 semantic_parity 与中间 semantic_verified 不覆盖；最终依据 semantic_final。implementation_snapshots 保存各次新模块的确切 SHA 版本，旧 seal 不改。不是放宽事实/端点相等要求。

下一步建议先讨论同文件接口/覆盖声明的共同绑定约束，以及合成节点来源能否从现有图结构得到唯一证明。不要退回按拼写替换，也不要先训练部分匿名、部分原名的混合视图。随机编号还可能保留文件规模/声明数量线索，保留名也仍存在；未跑 P2/P3 之前不能宣称匿名化已消除命名线索。
