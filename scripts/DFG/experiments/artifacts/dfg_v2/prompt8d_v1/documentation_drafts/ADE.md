## 2. A：自身文本变化与图上下文变化

实现：`scripts/DFG/dfg_v2/diagnostics8d/stratification.py`。

三个互斥分层，优先 a：

- a：该被评分节点 code 经 8C 标记名改写后确实变化。
- b：该节点 code 不变，但 AST 所属函数的声明名称确实改写。
- c：其余节点；无法确认的归属必须明确记录，不按近邻行号或相似文本猜测。

b 不是“所有连通节点”，也不是文本含函数名就算归属。普通节点用 Projector AST 身份，同文本语句在不同函数仍按 AST 祖先区分。字符串/注释里的标记不触发改名。函数归属是词法作用域，不代表完整 Solidity 调用解析。

## 3. D：作者附带漏洞行集合来源候选

## 4. E：标记名去除后的无学习规则

实现：`diagnostics8d/keyword_baselines.py`。

在冻结 8C 逐文件 idN 视图上，排除注释和字符串后识别：

- 访问控制：`tx.origin`，允许空白。
- 重入：`.call.value(`、`.send(`、`.transfer(`，允许空白。
- 导出当前节点文本、所属函数文本、二者 OR。OR 是主基线，另外两项分解范围影响；函数范围用 A_v2 精确 AST 祖先。

### 5.2 不变量和门槛

- 确定性生成候选并避开文件内名称碰撞。注释/字符串不改，普通对照排除受保护内建/环境/调用名称。
- 不仅检查孤立长度：逐节点检查未截断 token 长度、编辑位置及全部未编辑 token ID；最后仍原 512 维截断/补零 float32 inside_token。超长 tokenizer 提示来自未截断证明，不是改大特征。
- 仅干预当前折 outer_test 中准备清单包含的原节点；train/val/env_source 和未选节点不变。原 NetworkX 属性不写入，推理副本应用特征；原边/节点/标签不变。
- 仅加载原 best，不做 backward/optimizer；核验权重摘要、checkpoint 身份、图边和未改特征。
- 当前环境重入节点 fold0 G0 无干预门槛通过：argmax、float32 正类概率与归档逐位相同，最大差 0，零 optimizer steps。完整汇总重新校验 current_identity_gate 的 SHA、原计划/job/G0 图/feature recipe/实现和 checkpoint/state SHA。
- 每 job 独立进程、GPU 串行；错误停止保留日志，不自动重试/换 CPU。四份已绑定 worker 源码运行期间冻结。
- 汇总拒绝缺项、重复、错模式/身份、错 SHA 和部分未实施改写，必须齐 300 项成功状态。
- 分开比较 B_full−8C idN 与 C_matched−B_matched；不得把 B_full 与 C_matched 当同强度对照。
- orig/C1、来源 cohort、等权折均值/pooled 分开。非 SolidiFI 不作折均值结论；输出按正负标签翻转率、逐文件暴露、概率及错误变化。

B_full 与 idN 同时改变替换 token 取值和长度/位置，不能把差异全部解释成纯位置效应；匹配子集也未消除频次/上下文差异。本轮是测试时分布变化诊断，不证明中性化后重训效果。未进行改名程序编译验证，不称编译语义等价。此处没有提前填写全批结论。
