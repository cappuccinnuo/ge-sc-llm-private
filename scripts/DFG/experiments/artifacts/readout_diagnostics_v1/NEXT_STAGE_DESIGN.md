# 下一阶段：先验证合约读出是否能利用已有语义

设计/记录：Codex，2026-10-20。当前仅完成诊断和实验设计；本文件不是训练授权、冻结执行 plan 或新增训练 CLI。

## 1. 本轮明确保留与暂缓的事项

继续使用下载作者 CFG+CG 图、固定作者标签、既有 512 维 inside_token、文件折与已核验训练规则。DDG 已有四类关系及 CONTROL_DEPENDENCE 不再为了提高分数继续追加。困难节点保留，公共标注分歧作为旁路上下文，不替换正式 target 或删除样本。

合约诊断使用两个任务完整五折、三配置的 best。节点三分层对比包含 best/last，但不从中挑选更有利 checkpoint。全部属于 CV validation，不能解释为独立测试。

## 2. 从诊断到可检验假设

均值读出可能使局部证据与其他节点互相抵消，但正向局部证据在良性合约也可能很常见。因此，本轮只检验读出是否值得作为下一个整体实验变量，不能通过一个漏报例子认定平均汇聚是唯一根因。

不将现有隐藏向量的最大局部分数当作新模型成绩；不搜索 top-k、阈值、节点类型白名单或多种 pooling 后选择最好的 validation 分数。分类器每个节点的局部线性分数不是独立节点漏洞预测。

## 3. 建议只保留一个可学习读出候选

后续如开展正式验证，选择最小的、按文件归一化的注意力读出：

- HGT 输出保持 `h_i`；每个文件内 `s_i = a^T h_i`，`alpha = softmax(s)`。
- 合约向量 `g = sum(alpha_i h_i)`，仍为原隐藏维度，复用原二分类线性层。
- 不加入额外 MLP、节点标签引导、漏洞类别规则、位置规则、max 分支或可调 top-k。
- a 以全零初始化，不消耗额外随机数；初始权重均匀，数学上退化到 mean。128 维隐藏时仅新增 128 个参数，无需不可辨识的公共 score bias。
- 不冻结 HGT 或借用训练后的 encoder。仍从对应原未训练初值开始，全部既有可训练参数按原规则更新。

选择它的理由是允许模型在合约监督下学习权重；不是因为本轮已证明其一定优于 mean。朴素最大值会保留良性合约中的偶发高分，本轮不把它设为首选。增加注意力参数也会改变优化轨迹，收益不能全部写成依赖语义的因果贡献。

该候选尚未编码；现有训练脚本没有 `--readout attention` 参数，不能直接使用假定参数启动。

## 5. 实施顺序与验收

1. 旁路实现读出适配器，复用原 HGT、训练器和监督逻辑。核验每文件权重和为 1、没有串文件汇聚、梯度能达到 a 和 HGT。
2. 确定性核验零初值与 mean 的数学等价、同 dtype/device 下的有限数值误差；不得为逐位一致而在零初值时绕开 attention 梯度。
3. 按保存的未训练 checkpoint 和语义字典对齐共同参数。零初始化读出不改变原 RNG；fit 前显式恢复原 fit_seed。
4. 输入、标签、特征、关系 schema、fold、训练配置和 best/last 规则全部绑定；旧成功结果只读引用。
5. 先单折接口/显存检查，正式 fold0 可计入后续全折；输入、梯度或数值错误才停止，不因 F1 下降删折。
6. 正式实验最多新增 20 次串行拟合。best 按原最低 validation loss，last 独立辅助报告，不改变早停、学习率或 epoch 上限。

## 6. 应回答的问题

分别报告两任务逐折 Buggy-F1/Macro-F1、Precision/Recall、混淆矩阵、等权折均值、样本标准差、paired 差值、OOF、错误变化、概率变化、参数/显存/时间。

关键增量是：

`(增强图attention − HCG attention) − (增强图mean − HCG mean)`。

两图同时改善，只说明读出改进；增强图相对 HCG 的收益增加，才支持读出更有效利用新增关系的假设。仍需保留参数量和优化差异的解释边界。若各折不稳定或误报增加，应报告负结果，不继续堆关系来追分。

完成本轮诊断后不会自动执行这些拟合。当前只覆盖两个漏洞，七类通用性、额外 seed 和独立泛化评估尚无新证据。现有控制分析的接收者嵌套调用绑定边界另列后续正确性修复，当前封存图已核验命中函数均回退；读出实验不重新构图、不借此改历史数据。
