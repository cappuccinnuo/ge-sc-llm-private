# F2 保留限制

- 仅同编译单元唯一单继承链；多继承、复杂覆盖、未解析 import、祖先构造实参继续回退。
- 状态标量和简单 mapping；数组、嵌套 mapping、结构体、storage 引用、复杂键、跨函数/交易摘要未实现。
- modifier 仍整函数回退；权限检查与敏感操作的控制依赖未实现，也未冒充状态 Def–Use。
- 未知调用与外部调用采用保守全状态 HAVOC。UNKNOWN 是来源不确定，不证明状态一定改变。
- staticcall 未单独优化只读效应；开放版本区间没有可信精确元数据时保持未知。
- 事件顺序基于语义 CFG，未使用 SMT 证明路径条件、运行时余额、成功返回或漏洞可利用性。
- 只有已有 HCG 节点能作模型端点。emit 等锚点缺失导致部分真实事实不能物化；本轮不增节点。
- 同一 HCG 节点内多个事件无法用跨节点边表达；自边过滤，事实与损失均有记录。
- MAY/UNKNOWN 侧表不完备地枚举语言中所有可能别名；不能当成完整别名分析器。
- 原 20 Oracle 的 13 子集完成、7 回退不等于 20 个完整程序被认证。独立人工批准 0，solc 验证 0。
- 全语料是本批冻结的两类 Dataset A，未运行其他五类；未修改作者标签历史不确定性。
- 比较位置总量按函数位置累计，同一声明在不同函数可能计多次，不能当全局唯一状态变量数。
- 候选图不证明检测提升；本轮没有 F1、训练或对已训练模型的性能结论。
