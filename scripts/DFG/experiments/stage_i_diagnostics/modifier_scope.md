# “受限 modifier”是什么意思，为什么需要，原设计是否有

日期：2026-10-19；Codex。此文只解释候选范围和现有回退，不实现 modifier。

## 1. 不是按名称识别 onlyOwner

Solidity modifier（函数修饰器）可以在函数体前后插入执行逻辑。`_` 表示继续执行被包装的函数体或后续 modifier。它可能做权限判断，也可能记录日志、更新锁变量等；名字并不能决定其语义。

概念示例：

```solidity
modifier onlyOwner() {
    require(msg.sender == owner);
    _;
}
function setOwner(address next) public onlyOwner {
    owner = next;
}
```

这个示例用于说明语义，不是本轮编译验证的样例。分析只看 setOwner 的显式函数体，会漏掉执行它之前的 require；直接无条件忽略 modifier 也会错判控制流和状态访问。

必须区分两个问题：
- 解析并组合 modifier 的实际执行顺序；
- 在语义 CFG 上计算“哪些执行受哪些条件控制”。

实现第一项不等于已生成控制依赖，增加控制依赖也不能反过来省略 modifier 的绑定和执行语义。

## 2. 当前代码做了什么

当前**没有忽略后继续分析**，而是主动保守回退：
- 标量 `scripts/DFG/semantic_cfg.py:49–50` 检测 modifier_invocation 后抛 Unsupported。
- Stage F `scripts/DFG/state/stage_f/analyzer.py:21` 同样拒绝。
- Stage F `analyzer.py:88–92` 将该函数记录为 function_fallback，partial_state_facts_published=false。
- 原函数、原HCG节点/基础边/标签保留。状态阶段回退不会删除已冻结的原E2；它不发布本次未经确认的状态事实。

所以 modifier 是当前覆盖边界。尚未实现 modifier 支持是明确接受的范围限制，而不是可以悄悄按普通函数处理的情形。

## 3. 原来的设计有没有

准确区分：
1. 两份初始宏观方案 `MANDO_LLM_DDG_Code_Design_Guide.md` 与 `MANDO_LLM_第一阶段_DFG融合_方案文字说明.md` 没有明确展开 modifier/修饰符专项设计。不能把候选方案写成原文已完整要求或实现。
2. 后续 `DDG_INTEGRATION_ANALYSIS_2026-10-11.md:233` 明确写入：modifier、继承造成的绑定/控制影响，需要明确适配，首版无法可靠解析时回退，不忽略其存在。
3. `IMPLEMENTATION_NOTES.md:46,133` 与 `README.md:5` 记录了尚不支持 modifier、按函数回退的实施边界。
4. 本轮提出的“受限 modifier”是对该已知边界的候选分期解决方式，不是说明原第一版已经实现。

原宏观目标是通用语句级数据依赖；后续涉及权限相关行为时，必须正视 modifier 对执行路径的影响。但并不需要为了完成本轮第 1、2 步立刻扩展它。

## 4. “受限”的建议含义

先有明确可验证的小子集，再逐步扩展。候选首版可要求：
- 声明身份、继承可见性及调用绑定唯一，不能按名称字符串猜测；
- 参数绑定与求值顺序可确定；
- modifier 中只有一个可确定执行位置的 `_`；
- modifier 控制结构及副作用均在当前分析能力内；
- 函数体前后的事件顺序明确；异常、return 和 modifier 后置执行语义有独立测试；
- 多modifier组合、多个/条件性 `_`、复杂继承/重载、未知调用等先回退；
- 精确投影到原HCG；如果原图缺少modifier端点，则报告覆盖缺口，不按最近行号强配，也不擅自新增模型节点。

以上是**候选约束，尚未实现或批准为最终规范**。实际可支持边界须由源码和原图结构验证。不能以“多加几条权限边”为目标，也不能根据标签筛选是否生成边。

## 5. 需要的价值与验收

意义是恢复被函数体外包装逻辑影响的执行上下文；权限判断只是一个应用。修饰器有锁写入等行为时也可能影响其他漏洞，因此设计应保持通用。

验收应先检查正例、反例、回退样例中的绑定、执行次序、状态事件及投影，再检查覆盖量。新关系是否提升 F1 仍是后续独立实验问题，不能承诺加入 onlyOwner 或 modifier 支持就会提高访问控制分数。

本轮先用现成预测和状态事实判断：困难文件有多少问题确实源自 modifier 回退，而不是标签粒度、缺少原HCG节点、跨函数未知状态或模型未使用现有消息。证据成立后才选定实现范围。
