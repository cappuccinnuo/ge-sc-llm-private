# Stage J设计调整与验收范围

2026-10-19，Codex；版本 `ddg-stage-j-coverage-v1`。

## 为什么先做这些

Stage I显示：已有状态关系确实进入HGT，但与主要错误重合少；继承是比modifier更大的原回退类别。故本次先补覆盖，分为 frozen / inheritance / modifiers 三个独立候选，避免一口气扩展所有状态语义、改图节点或重训来掩盖问题。

“完成整体板块”指源码输入→绑定→独立语义CFG→事实→原HCG投影→关系融合→schema/模型接口→审计/配置形成闭环，不等于实现完整Solidity程序分析。旧宏观设计里的反向DDG和内部调用摘要仍不是当前E2/E3编号的含义。

## 继承与绑定

新增同一源码中唯一声明的基类查找；支持无构造参数的有限多继承、菱形继承和仅声明的interface。按Solidity右侧直接基类优先的C3计算顺序并检查不一致；同一祖先只进入一次。状态位置继续使用源码SHA、所属声明及字节跨度，不能仅按变量名合并。

有import、找不到基类、重复基类、循环/不一致C3、library作为基类、基类构造参数、不可唯一绑定成员时回退。没有新增重载/override选择规则或内部调用摘要，调用仍按已有绑定/HAVOC策略。private基类状态无法在当前解析上下文确认时宁可回退；不能声称完整继承解析。

参考：[Solidity 0.4.26继承与线性化](https://docs.soliditylang.org/en/v0.4.26/contracts.html#multiple-inheritance-and-linearization)。

## 受限modifier到底支持什么

支持一个函数调用一个唯一绑定、无参数的modifier，modifier体是可分析的直线前缀，最后恰有一个顶层`_;`：

```solidity
modifier onlyOwner() {
    require(msg.sender == owner);
    _;
}
```

本例展开为“读取owner并检查→执行函数体”。如果函数体之后写owner，可以形成同一状态位置的访问顺序；读取owner本身不是owner的定义，也不能直接变成“权限检查控制所有敏感操作”的控制依赖。

支持范围内前缀赋值/更新参与原状态到达定义；require/assert须确认内建绑定与版本，无shadowing、嵌套未知调用。函数局部同名变量不会遮蔽modifier声明中的状态变量。原字节跨度不改，原HCG已有modifier语句才能投影；多个调用上下文可共享原声明节点，但证据保留各自函数身份。

暂不支持参数代入、多modifier、前缀局部声明、条件/循环占位符、多个占位符、`_;`后的后缀、嵌套或可能产生副作用的guard调用。尤其不把带后缀解锁的nonReentrant假装成普通前置检查。Solidity modifier的后缀和return存在专门语义，首版排除后缀以避免错误执行次序：[官方modifier说明](https://docs.soliditylang.org/en/v0.4.26/contracts.html#function-modifiers)。

## 函数级隔离与投影

1. 先执行冻结Stage F分析；已成功函数的结果对象保持原样。
2. 仅重试回退函数。新的函数分析完全成功后才提交事实。
3. 不支持时函数级回退，记录函数名、span、源码SHA、判定依据；不发布部分事实、不删除样本。
4. 复用精确token/AST对应的Projector；没有HCG端点则记录缺失，绝不找最近行号。
5. 未投影的写入仍参与语义覆盖；未投影控制结构仍参与语义CFG。
6. 投影事实只添加现有节点间边，同端点不同relation可共存；同关系同端点合并，证据侧表保留。
7. 图指纹验证原节点、顺序、属性、token、标签和基础边不变；增强只发生在schema提取前。

## 测试与验收

新增54项测试，连同旧DDG模块共377项通过；原项目25项回归通过。测试包括：

- 继承、菱形、private、冲突、声明顺序和未知绑定；
- modifier参数/后缀/多占位符等回退；参数入口、循环、KILL和return保留；
- 回退无残留、另一函数不受影响；
- 标签/token值扰动不改变构图结果；
- 缺失写入端点不恢复被覆盖的旧定义；
- 同端点多关系、四种关系正向schema；
- 原HGTLayer真实读取新关系，梯度有限且非零，checkpoint重载；不更新模型；
- CLI输入SHA错误/输出覆盖拒绝及端到端生成。

所有新增Solidity样例均为解析/静态语义回归夹具。**没有运行solc编译验证，也没有把Tree-sitter可解析当作语言合法性证明。** 没有下载或执行新编译器。官方语言规则和保守回退辅助设计，不能替代完整编译器绑定。

真实数据12图通过基础图指纹、关系方向、SHA和冻结Stage F关系集合复现；H1/H2历史60/30结果只读复核通过。详情以本批报告、日志及收据为准。
